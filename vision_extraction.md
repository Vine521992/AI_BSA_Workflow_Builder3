# Vision document analysis prompt

Act as a careful document analyst. Inspect every supplied page/image, including screenshots, diagrams, flowcharts, tables and scanned text. Extract only content that is legible and supported by the source. Preserve requirement IDs, labels, table headings, relationships, decision branches and page numbers where visible. Do not infer missing text from context. Return structured evidence with: page/source location, content type, verbatim or faithful extraction, interpretation (clearly labelled), confidence (high/medium/low), and unreadable/ambiguous areas.
