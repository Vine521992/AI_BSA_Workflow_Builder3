# BRD-to-FSD generation prompt

Transform the supplied BRD evidence into a Functional Specification Document. Apply universal brand, voice and BA standards plus any project override. Include Document Control; Purpose and Scope; Background and Objectives; BRD Summary; Functional Requirements; Business Rules; Data Requirements; Process Flows; Interfaces and Integrations; Validations and Exception Handling; Non-Functional Requirements; Dependencies and Assumptions; Acceptance Criteria; Requirements Traceability Matrix; Open Questions and BA Decisions. Preserve original IDs. Mark generated IDs provisional. Do not invent facts, rules, fields, data types, interfaces or acceptance criteria. Label assumptions and recommendations. Explicitly list contradictions and source locations. Return self-contained HTML only.
